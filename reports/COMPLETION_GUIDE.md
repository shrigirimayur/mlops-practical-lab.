# Submission completion guide

This archive is the project source package. It cannot push itself to a personal GitHub account, and DVC output cannot honestly be recorded without running the DVC CLI. To complete the two environment-dependent parts:

1. Install Git and Python 3.10+.
2. In the project root, run `python -m pip install -r requirements.txt`.
3. Run `python scripts/run_python_experiments.py`.
4. Run `python scripts/run_dvc_practical.py` and keep the real terminal output.
5. Run the Git branch/merge/conflict exercise in Experiment 2.
6. Create your GitHub repository and upload the extracted project contents.

Do not submit a prewritten success log as proof of a command you did not execute. Use the actual output from your machine.
