# Practical Report Completion Guide

For each experiment, complete these sections with your own work:

1. Experiment number and title
2. Aim and learning objectives
3. Theory
4. Software/tools and versions
5. Procedure and commands executed
6. Code/configuration
7. Actual output (terminal text or screenshot)
8. Observations and analysis
9. Result/conclusion
10. Viva questions and answers

**Do not use illustrative sample output as proof of execution.** If a component could not be run, document the limitation and the next step needed.
